# nancy_cake

Website for **Nancy Cake House**, a patisserie in Madhavaram, Chennai: *Baked with love*.

- `index.html`: the single-page site (menu & price list, gallery, Instagram section, WhatsApp order form)
- `images/`: logo and cake photos (see `images/README.txt`)

Open `index.html` in a browser to view it. To deploy, upload `index.html` + `images/` to any static host (GitHub Pages, Netlify, etc.).
